# Muhammad Farooq — Portfolio Website

A modern, responsive, and high performance portfolio website built to showcase my projects, skills, and professional journey. Designed with a clean user interface, smooth user experience, and optimized performance across all devices.

## 🚀 Tech Stack

* React 19
* Vite 7
* TypeScript
* Tailwind CSS v4
* Shadcn UI
* Radix UI
* React Router DOM
* Lucide React Icons
* Progressive Web App (PWA)
* ESLint & Prettier

## 📋 Prerequisites

Make sure you have the following installed:

* Node.js
* npm

## ⚡ Getting Started

Clone the repository and install dependencies:

```bash
git clone <git@github.com:enmfarooq85/enmfarooq85.github.io.git>
cd enmfarooq85.github.io
npm install
```

Start the development server:

```bash
npm run dev
```

## 🛠 Available Commands

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Format Code

```bash
npm run format
```

## 🚀 Deployment

After updating portfolio content:

```bash
git add .
git commit -m "Update portfolio content"
git push origin main
npm run build
npm run deploy
```
